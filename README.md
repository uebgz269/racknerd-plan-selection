## 1GB 够不够用，2GB 贵出来的 $14 花在哪

1GB 内存跑一个 WordPress 站是可行的，前提是插件别乱装、MySQL 调小一点、配个 swap。真正吃内存的是那些你以为不起眼的东西：宝塔面板本身、数据库、定时备份、日志分析，几个加起来就把 1GB 吃满了。共用主机上跑两三个站，页面一多就开始 OOM，然后你会在半夜收到监控告警。

2GB 那档多出来的不只是内存，还有 1 个 vCPU 核心和 15GB 硬盘空间，年付只贵 $14。换算下来一个月多一块多美元。这笔钱值不值，看你属于哪种情况：

- 只放一个静态站、一个博客、或者当跳板和中转，1GB 完全够，多花的钱用不上。
- 要装宝塔、要跑 MySQL、要放两个以上站点、要跑 Docker，直接上 2GB，别在 1GB 上折腾 swap 优化，省下的时间比 $14 值钱。
- 4GB 及以上属于另一类需求：多站点 + 数据库 + 缓存 + 定时任务同时压着跑，或者你要跑内存占用明显的应用。

6GB 和 8GB 这两档，个人用户基本用不上。它们的意义在于给多进程、编译构建、小型数据集处理这类活儿留余量，或者对应下面说的一键应用里那几个内存要求最高的工具。

## 常见问题

### 1GB 内存真的能跑 WordPress 吗？

能跑，但要节制。插件控制在必要范围内，数据库配置调小，加一个 swap 文件兜底。日访问量上千、装了缓存插件和统计插件之后，1GB 会开始紧张，这时候升到 2GB 比继续调优划算。

### 能在面板里升级套餐吗？

可以。ctrl 面板带升级功能，也能重装系统、用 HTML5 VNC 控制台排障、改 root 密码、设置网络防火墙入站规则。重装只要一两分钟。

### 美国机房需要备案吗？

服务器在美国，不涉及国内 ICP 备案流程。域名解析到境外服务器时的具体要求，取决于域名注册商和接入方式，跟服务器本身无关。

### 支持 IPv6 吗？

洛杉矶和法国机房可以工单免费申请，最多 100 个，下单后开工单让客服配置。其他机房的支持范围在逐步扩大。

### 国内访问速度怎么样？

看机房。洛杉矶 DC02 走三网直连，是这批位置里国内体验相对好的；圣何塞、西雅图也可以考虑。没有 CN2 GIA 优化线路，晚高峰会有波动，做外贸站或面向美国用户的项目基本不受影响，对延迟极敏感的实时应用要另想办法。
